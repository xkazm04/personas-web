## Section 3 - Memory (`MemoryLayers`, section id `memory-layers`, tour anchor `memory`)

Claim: agents remember what works: every run adds memories (learning, preference,
technical, constraint), the important ones stay on top and are recalled instantly,
so agents get better the more they work. Real categories and colours in
`memoryShared.tsx` (`CATEGORY_META` or equivalent). Keep the tour anchor.

- **sediment** (mechanism). Structure: a tall glass column; each run drops coloured
  grains that settle into four coloured strata (the four categories); strata thicken
  over beats; the most important grains glow and float to the top edge where a
  "recall" bracket catches them. Muted: runs deposit layers; the best rise.
  Word list: `Learning`, `Preference`, `Technical`, `Constraint`, `Run`, `Recall`.
- **constellation** (spatial). Structure: nodes in four colour clusters; each beat a
  new run adds a node that links to its nearest relatives; on the last beat a
  recall path lights across several nodes to the agent glyph at the centre.
  Muted: knowledge grows as a connected map and is traced on demand. Word list: the
  four category names and `Agent`.
- **run-twice** (transformation). Structure: two parallel tracks from start to goal.
  Top track (Run 1): a wandering path with retry loops and two red cross marks.
  Bottom track (Run 12): a straight path, with small memory chips (coloured by
  category) attaching at the points where run 1 failed. Beats: run 1 draws, then run
  12 draws faster. Muted: the same task, first messy, later direct because of what was
  kept. Word list: `Run 1`, `Run 12`, `Memory`.
