# Runbook: regenerate the changelog feed

**When:** the desktop app's `CHANGELOG.md` gained a release section, or
`npm run check:changelog` reports drift.

`src/data/changelog.generated.ts` is generated by `scripts/compile-changelog.mjs` from the
desktop checkout (`../personas`). It is never edited by hand. The rules for which bullets
are public are in the header of that script. The check exits 0 with "skipped" when no
desktop checkout exists, as on CI runners.

## Steps

1. Make sure `../personas` is checked out at the revision you mean to publish.
2. `npm run check:changelog`: see whether the generated file is behind.
3. `npm run compile:changelog`: rewrite it.
4. `npm run typecheck` and `npm run lint`.
5. Commit only `src/data/changelog.generated.ts`, with the desktop revision in the message.

The same shape applies to the desktop facts snapshot (`npm run sync:desktop-facts`, checked
in CI with `-- --check`) and to the connectors catalog (`npm run check:connectors`).
